# Шпаргалка: обмен встал

Не про мониторинг процессов и не про постоянный просмотр логов. Минимальный артефакт на тот день, когда **внезапно** нужно понять, куда смотреть — чтобы не терять время в панике.

**Источник правды по работе обмена** — [functional-contract.md](functional-contract.md) и код. Этот файл — опциональная страховка.

## Куда ткнуть (заполнить под проект)

| Что | Где |
| --- | --- |
| Вход CRM → сайт | `POST` на `/local/classes/ajax.php`, поле `ACTION` |
| Базовый URL сайта для CRM | константа вроде `EKLEKTIKA_SITE_URL` (где в B24 задаётся) |
| Кто шлёт на сайт | классы вроде `Updater::sendRequest` в `eklektika-ru-b24`, откуда вызывается |
| Исходящий сайт → CRM | `URL_B24`, обёртки в `local/classes/b24/` (до переноса в `sync/`) |

## Типичный сбой: сайт недоступен с CRM

1. Проверить доступность URL сайта из контура, где крутится B24 (сеть, DNS, TLS).
2. Проверить, что `EKLEKTIKA_SITE_URL` / окружение указывают на тот стенд, который вы реально чините.
3. Дальше — по [functional-contract.md](functional-contract.md) §5 (повторы отправителя) и коду `Updater`.

Если понадобятся детали по лимитам тел запросов или таймаутам — см. §3 контракта и при необходимости допишите сюда одну строку, а не отдельная «культура алертов».
