# S1: Bootstrap PHPUnit в `local/`

- Главная задача: `../README.md`
- Статус: `done`

## Цель

Подготовить минимальный рабочий фундамент для тестов в `local/`: `composer.json`, `phpunit.xml`, базовые директории и автозагрузка тестов.

## Объем работ

- Добавить `local/composer.json` с dev-зависимостью PHPUnit.
- Определить в `local/phpunit.xml` базовый suite для unit-тестов.
- Создать каркас `local/tests/Unit` и общий bootstrap для unit-фазы (без Bitrix init).
- Проверить, что команда запуска тестов выполняется в WSL PHP 8.2.

## Входы

- ADR: `../../adr/2026-05-02-phpunit-local-reliability.md`
- Актуальная структура модулей в `local/modules/*`.

## Выходы

- Рабочая инфраструктура запуска unit-тестов из `local/`.
- Задокументированный базовый запуск (команда + ожидаемый output).

## Зависимости

- Без внешних зависимостей по коду; блокирует старт `S2`.

## Риски

- Конфликт путей автозагрузки между модулями.
- Несовпадение расширений PHP между WSL и CI.

## Индивидуальные критерии готовности

1. В `local/` присутствуют `composer.json` и `phpunit.xml` с валидной конфигурацией.
2. Выполняется хотя бы один тестовый запуск PHPUnit в WSL без фатальных ошибок bootstrap.
3. Unit bootstrap не тянет Bitrix ядро и не требует окружения production.

## Чеклист проверки результата

- [x] `composer test` / `vendor/bin/phpunit -c phpunit.xml` — зелёный прогон (16/16, PHP 8.2.30).
- [x] Структура `tests/Unit` и правила именования тестов согласованы.
