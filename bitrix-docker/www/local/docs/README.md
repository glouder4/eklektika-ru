# Docs (Project documentation entrypoint)

Эта папка — **единая точка входа проектной документации** (source of truth для бизнес‑процессов и интеграций).

Ключевой фокус сейчас: **регистрация юрлица/рекламного агента** + **интеграция с CRM через n8n webhooks**.

## Оглавление

- Бизнес‑процессы: `docs/business-processes/README.md`
- Справочники/контракты интеграций: `docs/reference/README.md`

## Правило изменения процесса

Если меняется хотя бы одно из:

- порядок шагов процесса;
- точки входа (URL/handlers/services);
- ветвления/условия отказа (ambiguous company, duplicate contact, INN empty и т.п.);
- rollback/откаты (например удаление пользователя при failed CRM sync);
- список вебхуков, их URL/пути, контракт payload/ответов;
- ключи конфигурации и их смысл;

то изменения считаются **незавершёнными**, пока не обновлены документы в `docs/` (в том же PR).
