# Business processes

Каноническое описание бизнес‑процессов проекта.

## Процессы

- Регистрация (синхронизация с CRM через n8n): `docs/business-processes/registration/README.md`

## Общие принципы

- Процессы в этом разделе описываются в терминах: **входы → шаги → ветвления → выходы/побочные эффекты → откаты**.
- Для каждого процесса фиксируются:
  - **точки входа** (URL/handlers/services),
  - **порядок вызовов** (что за чем и почему),
  - **контракты интеграций** (ссылки на `docs/reference/*`),
  - **Definition of Done** для изменения процесса.
